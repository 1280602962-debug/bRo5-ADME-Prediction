# M5 执行记录

分支 `model-development-m5` 从 `8f7d9df` 建立。结果只写在 `runs/model_development_m5/`。M4 及更早阶段的文件不覆盖。终点仍是 Caco-2 A→B 的 log10(Papp [cm/s])。106 个封存的非大环、分子量大于 700 Da 的图及其隔离关系不进入新特征、训练、阈值或预测。

本文件记录已经批准并执行的方案。它不是新的待确认计划。

## 保持不变的部分

研究问题是小的三维增益是否受随机森林种子和构象质量影响，有没有新的实验监督，哪类三维信息值得继续计算，以及现有模型能否支持系列排序或可靠性筛选。M4 的六项主比较及其多重比较校正结论不替换。不运行 M5.4 的正式 GPU 推理，不新增 Optuna、神经网络、全开发池 CREST 或分子动力学。

## 执行细则

M5.0 按原划分和特征可用性重建每个外折、每个模型臂的训练标签集合。历史预测文件没有保存训练成员，只保存测试标签和训练数量。复核区分代码重建的预期成员和历史文件能直接证明的测试成员。不另做哈希审计。重复测量检查同一 measurement_id 是否被重复加权。不同 measurement_id 只表示可能不同的测量记录。

M5.0a 做 60 次拟合，种子是 17、42、101。四个模型共用训练成员、标签顺序、外折和固定随机森林参数。种子不从模型名推导。报告各种子、种子平均绝对误差和配对区间。这些区间是敏感性结果，不替换 M4。

M5.0b 对同一批初始构象分别套用严格收敛和原来的接受规则。20 个分子来自原稳定性试点，另外 20 个来自原合格集合。分别统计未收敛比例、集合资格翻转比例和描述符超过工程阈值的比例。至少 10 个分子发生资格翻转，或出现系统性立体化学错误，或出现类别性描述符偏差时，暂停基于现有构象的进一步科学解释。不自动重算 2176 个图。

M5.1 核对五个来源。Kim 2025 的 32 个 Caco-2 A→B 分子已在封存集，不重新提取，也不计算新特征。其他来源分别统计原始记录、合格标签、新增图和隔离后实际可用训练图。先做容量判断。不修改冻结训练数据，不做多任务训练。

M5.2 增加预测变化为零的基线和随机方向参照。预测变化恰好为零时不算方向正确。分子对只保留一次。MMP 和相似对分开报告。0.3 和 1.0 log 单位是预设应用阈值，不是已验证的实验误差界限。兼容条件下的分子对不足时直接报告不可充分评价，不放宽条件。组级消融仍做 45 次新拟合，并保持探索性。

M5.3 与其他 CPU 工作独立。软件安装失败或资源不足不阻断其余模块。若重生成构象，除最低能量外还核对回转半径、极性溶剂可及表面积和分子内氢键。不能复现时作为独立先导构象。L2a/L2b 与 L2c 各不超过 96 CPU 核时，累计不超过 192。不自动扩大分子数，也不据此建立正式模型。

M5.5 先做全覆盖的最近邻 Tanimoto、树间预测离散度和 F04/F05 预测差。与 P4 有关的分数单独报告覆盖率。若建立浅层误差模型，用训练侧外折内预测的绝对误差作监督，并用训练侧交叉拟合风险确定拒识阈值。随机拒识重复 150 次，分子覆盖口径与可靠性拒识一致。同时报告保留的分子数、标签数、研究数、MAE 和排序指标。拒识后的子集性能不写成全覆盖精度提高。
