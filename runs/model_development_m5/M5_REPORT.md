## 种子和构象

四个模型共用种子 17、42 和 101，标签按 label_id 排序，随机森林参数固定。比较的是各种子绝对误差的平均，不是平均预测的绝对误差。这些是敏感性区间，不替换 M4。

在 430 个标签、135 个研究上，集合特征相对 F04 的种子平均差是 −0.0155，95% 区间 [−0.0328, 0.0012]，包含 0。三个种子里只有 101 的单独区间不含 0。相对 F05 的差是 −0.0047，区间 [−0.0253, 0.0164]。集合相对静态三维的差是 −0.0051，区间 [−0.0138, 0.0031]。后两项的三个种子区间都包含 0。同一数据和特征上，源 MAE 的种子极差大约是 0.004 到 0.006。

40 个分子使用同一次构象生成和优化，再分别套用严格收敛和原来的接受规则。未收敛构象比例是 0，集合资格翻转是 0，回转半径、极性溶剂可及表面积和分子内氢键超过原工程阈值的分子比例是 0。立体化学核对没有发现原子或双键变化，也没有类别性描述符偏差。因此没有暂停解释，也没有重算全部构象。个别分子超过阈值本就不会停止计算；这次没有这样的分子。

## 组消融和系列方向

45 次新拟合是探索性的。几何组相对 F04 的差是 −0.0015，区间包含 0。极性暴露组是 −0.0146，区间 [−0.0267, −0.0026]，不含 0。分子内氢键组是 −0.0016，区间包含 0。这些没有加入 M4 的六项主比较。

描述符相关只作描述：分子量和三维体积的 Spearman 相关是 0.942，TPSA 和极性溶剂可及表面积是 0.829，氢键供体和分子内氢键是 0.549，氢键受体和分子内氢键是 0.280。相关不是因果。

外折测试标签里，有信息的实验条件记录是 0 条。同一外折、同一研究中有 86 个研究、2189 个无序分子对，但它们的条件标记都是缺失或不确认。MMP 和相似对都因此为 0。0.3 和 1.0 log 单位仍只是预设应用阈值。按预定规则，系列方向不可充分评价，条件没有放宽。预测变化恰好为零时不会被算作方向正确；这次没有可评分的兼容条件分子对，因此也没有报告方向准确率。预测变化为零的基线是实验变化绝对值的平均，随机方向参照是 0.5。这两项都因没有可评价分子对而没有数值结果。

## 溶剂探针

xTB 6.8.0 安装在独立环境 `m5_xtb`。使用的是 ALPB 的 `water` 和 `chcl3`。GBSA 的溶剂名是 `H2O` 和 `CHCl3`，这次没有混用。机器上没有 CREST，也没有集群调度器。

只计算了一个电荷为 0 的 500–700 Da 非大环分子 `G_5f8e58ce69524ec9e26caee1`，三个起点。重新生成的最低能量构象在能量、回转半径、极性溶剂可及表面积和分子内氢键上与保存的 M4 构象一致，因此这不是一套独立先导几何。

同一几何上，氯仿减去水的能量差大约是 −11.36 到 −11.65 kcal/mol，三个起点的跨度是 0.29 kcal/mol。这是同一几何上的能量差，不是膜转移自由能。分开做局部优化后，两个溶剂的能量差跨度大约是 1.0 kcal/mol。极性溶剂可及表面积的变化并不稳定：多数起点变化接近 0 到 +2 Å²，一个氯仿优化变化约 −5.9 Å²。分子内氢键计数没有变化。结构连接在这六次优化里保留了下来。

累计约 0.004 CPU 核时，低于 192 的上限。没有扩大到 8–12 个分子，没有做 L2c，也没有据此训练模型。

## 可靠性

全覆盖基线是种子 17 的固定随机森林 F05，530 个标签、515 个分子、153 个研究。源 MAE 是 0.573，Spearman 相关是 0.208。这是这次指定种子的重拟合，不是 M4 那个由模型名决定种子的结果。

最近邻距离、树间离散度和 F04 与 F05 的预测差都在全部外折上计算。与集合特征有关的预测差只覆盖 430 个标签、418 个分子、135 个研究，约占分子的 81%。平均绝对预测差是 0.117。缺失处没有填补。

浅层岭回归用训练侧内折预测的绝对误差作监督。五个外折上，交叉拟合风险和误差的 Spearman 相关是 −0.11、−0.05、0.08、0.18 和 0.14。符号不稳定，训练侧不支持一个可用的误差模型。阈值仍只来自训练侧风险，没有用外折测试误差来定阈值。

拒识后的源 MAE 落在 150 次随机拒识的区间里面，或只擦到区间边缘。例如最近邻保留约 80% 分子时 MAE 是 0.548，随机参照的区间下沿是 0.549。保留更少分子时，最近邻和岭回归的子集 MAE 都落在随机参照区间内。树间离散度和 F04/F05 差值没有给出更低的子集误差。因此不能说较低风险的分子已被识别，更不能说全覆盖预测精度提高了。随机参照使用与可靠性规则相同的逐折分子数；随机行里的标签数、分子数和研究数是 150 次抽取的平均。

## 七个问题

弱的三维增益对共享随机种子不稳定。种子平均后，集合特征相对 F04 的区间包含 0。40 个分子的构象复核没有发现未收敛、资格翻转或描述符越限，所以这次没有把增益的不稳定归到构象质量。

极性暴露是三组里唯一一个探索性区间不含 0 的组，但差值只有约 0.015，而且极性和 TPSA 高度相关。这不足以开始一轮新的表示计算，也没有进入主比较。

没有找到可以在现行冻结规则下加入开发集的新 Caco-2 A→B 监督。

当前模型能不能预测系列内渗透性变化的方向，不能充分评价。外折测试里没有兼容且条件明确的分子对。

溶剂计算在一个分子的三个起点上给出了符号一致的能量差，但极性表面的变化不稳定。它没有提供可以进入模型的稳定新信息。

现有分数不能可靠地找出较低误差的分子。训练侧误差模型不稳定，子集误差也没有稳定地低于同等分子覆盖的随机拒识。

没有证据支持开始 GPU 阶段或更大的物理化学计算。
