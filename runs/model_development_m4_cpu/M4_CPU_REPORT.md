# M4-CPU 报告

终点是 Caco-2 A→B 的 log10(Papp [cm/s])。评价沿用阶段 B 的来源等权 MAE：标签绝对误差先在研究内按图平均，再对研究等权。Bootstrap 使用 10000 次研究–骨架连通分量重抽样，随机数种子 271828。本轮结果仍是开发性泛化，因为评价 C 已经参与过先前的模型决策。

## 测量重复

开发池有 7 组研究内独立重复，184 组数据库重复收录。跨研究、且 protocol token 不是缺失标记的兼容重复组为 0。因此不能充分量化研究间变异，没有做方差分解。独立重复组的标准差中位数见 M4.0 报告，数量太少，不能当作模型误差下限，也不能把实验异质性写成已经证实的模型失败原因。

## 电离

MolGpKa 对 2511 个开发图都给出了位点 pKa。类别计数为 {'multi_site_or_zwitterion': 1992, 'multi_site': 360, 'single_base': 69, 'single_acid': 42, 'no_ionizable_site': 39, 'permanent_charge': 9}。单位点 Henderson–Hasselbalch 只适用于 111 个没有永久电荷、记录结构为中性且只有一个预测位点的分子。中性分数没有进入模型。进入模型的是位点计数和最酸/最碱 pKa 的存在性编码。

SAMPL 公开集合的分子量范围是 150.2–440.4，大环 0 个，匹配 MAE 0.625。这不是 pKaHub 论文里已经排除训练重叠的单质子、两性和多质子子集，那些名单没有作为独立文件发布。它也不能证明工具已经覆盖本项目的高分子量、多位点和大环分子。pH 6.5 和 7.4 只是参考计算环境。

## 模型

共同样本上的 P4 来源等权 MAE 是 0.5991，同一批 430 条标签上的 P0 是 0.6165。这 430 条标签的 MAE 不能和全部 530 条标签的历史 MAE 直接比较。本轮在全部 530 条标签上重新拟合的 F04 随机森林来源等权 MAE 是 0.5815；种子与 M3 不同，因此不把它写成 M3 数值的逐位复现。预先规定的全覆盖回退（有可靠构象集合的标签用 P4，其余用完整训练集上的 F04）是 0.5696。回退结果单独报告，没有在看到数值后加入六项主要比较。

五个外折里有 3 个外折的内部验证显示 P4 低于 P0。四折门槛没有达到，没有增加 XGBoost。评价 A/B 使用预先固定的随机森林和预先登记的 P4，没有继承评价 C 选出的配置。A/B 的来源等权 MAE：A P0 0.4899, A P4 0.4898, B P0 0.5045, B P4 0.5072。

P2-P0 的来源等权 MAE 差（候选减参照）是 -0.0096，候选一侧较低。95% 区间是 [-0.0271, 0.0079]，Bonferroni 约 99.17% 区间是 [-0.0336, 0.0130]。普通 95% 区间包含 0。校正区间包含 0。 P3-P0 的来源等权 MAE 差（候选减参照）是 -0.0157，候选一侧较低。95% 区间是 [-0.0313, -0.0002]，Bonferroni 约 99.17% 区间是 [-0.0361, 0.0050]。普通 95% 区间不包含 0。校正区间包含 0。 P4-P0 的来源等权 MAE 差（候选减参照）是 -0.0173，候选一侧较低。95% 区间是 [-0.0354, -0.0001]，Bonferroni 约 99.17% 区间是 [-0.0409, 0.0056]。普通 95% 区间不包含 0。校正区间包含 0。 P4-P3 的来源等权 MAE 差（候选减参照）是 -0.0052，候选一侧较低。95% 区间是 [-0.0159, 0.0051]，Bonferroni 约 99.17% 区间是 [-0.0194, 0.0084]。普通 95% 区间包含 0。校正区间包含 0。 P5-P4 的来源等权 MAE 差（候选减参照）是 -0.0013，候选一侧较低。95% 区间是 [-0.0162, 0.0141]，Bonferroni 约 99.17% 区间是 [-0.0211, 0.0195]。普通 95% 区间包含 0。校正区间包含 0。 P5-P2 的来源等权 MAE 差（候选减参照）是 -0.0035，候选一侧较低。95% 区间是 [-0.0210, 0.0142]，Bonferroni 约 99.17% 区间是 [-0.0277, 0.0203]。普通 95% 区间包含 0。校正区间包含 0。 P4-P1 的来源等权 MAE 差（候选减参照）是 -0.0031，候选一侧较低。95% 区间是 [-0.0229, 0.0171]。普通 95% 区间包含 0。

负值表示候选的来源等权 MAE 更低。P4−P0 是本轮核心比较。P3−P0 和 P4−P0 的 95% 区间下沿非常接近 0，六比较校正后的区间都包含 0。P4−P1 的探索性区间包含 0，不能说三维集合表征优于充分扩展的二维 F05。P4−P3、P5−P4 和 P5−P2 的区间也包含 0。电离比较使用的是 MolGpKa 位点计数，不是微观物种分数；它们可以执行，所以没有被标成缺失，家族规模仍是 6。

外折 0 上，打乱单个特征后的标签 MAE 变化：ens_Volume_median 0.0158, ens_PolarSASA_p10 0.0120, ens_PolarFraction_median 0.0084, ens_PolarSASA_median 0.0074, ens_PolarFraction_p10 0.0054, MW 0.0050。这是一个外折上的置换结果，不是因果贡献，也没有据此增删描述符。极性表面积的置换变化大于回转半径和分子内氢键，但配对模型比较才是预先规定的证据。

特征覆盖率在 `m4_coverage_metrics.csv`。评价 C 的 530 条测试标签中，430 条有可靠构象集合，438 条至少有一个静态构象，电离特征覆盖全部 530 条。

## 溶剂与能量

本机没有 CREST，也没有 xTB。没有做水相/氯仿配对试算，没有累计 12–20 个分子的预算，也没有把固定几何的环境能量差写成膜自由能。M4.4 和 M4.5 没有结果，不能用来声称溶剂响应或能量代理已经改善渗透预测。

## 对后续计算的含义

P3−P0 和 P4−P0 的普通 95% 区间刚好不包含 0，校正后的区间包含 0。这不是启动 GPU 分子动力学、神经网络或多任务学习的依据。 没有新增 Optuna、Mordred、PaDEL、神经网络或大规模半经验构象搜索。
