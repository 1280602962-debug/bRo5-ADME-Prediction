# M4.0 实验测量异质性

终点保持冻结的 Caco-2 A→B log10(Papp [cm/s])。统计只使用开发池中的 2511 个图，不包含 106 个封存图。没有改写冻结标签。

`condition_id` 的结构是 `STRICT|source_token|protocol_token`。在开发池的主终点记录中，source token 多数是 `CHEMBL_ASSAY:` 实验编号，不是文献 DOI。研究来源在单独的 `study_id` 字段。若只用完整 `condition_id` 寻找跨研究重复，assay 编号会把不同研究拆开。因此另外按去掉 assay 编号后的 protocol token 计数。`NOT_REPORTED`、`UNKNOWN` 和其他缺失标记单独统计；相同缺失标记不视为实验条件相同。

开发池主终点原始记录 3032 条，覆盖 2511 个图和 553 个研究。同一分子、同一研究、同一 condition_id 下，有 184 组是同一 `measurement_id` 的多条数据库记录，记为重复收录，不作为独立测量。测量编号不同且数值不同的组有 7 个。测量编号不同但数值相同的组有 1 个。

按完整 condition_id，跨研究组有 1 个。去掉缺失 protocol 后，按 protocol token 的跨研究组有 0 个。缺失标记本身如果被错误当成相同条件，会得到 42 个跨研究组，这些组没有使用。有 47 个分子出现在一个以上的研究中，但没有足够的已知兼容条件把它们配成重复测量。

因此不能充分量化研究间变异，没有做方差分解或混合效应模型。也不能把实验异质性写成已经证实的模型失败原因。独立重复组的标准差中位数是 0.094。这些组里能连到评价 C 的 RF-F04/F05 预测的分子数记录在 `repeat_error_link.csv`。数量很少，只作描述，不解释为因果，也不写成全体分子的预测误差下限。

整理表中的 pH 与抑制剂注释只说明注释覆盖率。数值 pH 很少，绝大多数为 UNKNOWN。pH 6.5 和 7.4 不是这些原始实验已被证实的统一 pH。
