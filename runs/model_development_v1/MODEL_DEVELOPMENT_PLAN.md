# bRo5-Perm 执行记录（M0–M3）

本文件记录已经批准并实际执行的方案。研究边界、数据冻结、模型候选、主要优化上限和停止条件没有改动。下面只列出执行时落实的修订和实际拟合次数。

终点是 Caco-2 A→B log10(Papp [cm/s])。父提交是阶段 C 收尾 `218cb8f`。106 个 MW>700 Da 非大环图及关联隔离数据保持封存。

## 已执行的范围

阶段 C 只归档 C02 的八个策略。不补跑缺失的 C01 XGBoost 或 D-MPNN，也不把没有训练源码的任务写成独立复现。

评价 C 是主要评价，完成了内部筛选和 G1 的 Optuna。评价 A/B 使用预先固定的 RF、XGBoost、LightGBM 和完整 RDKit 二维描述符加 ECFP4。没有把评价 C 的优选配置用于 A/B，也没有复制搜索矩阵。

G1、G2、G3 共用每个外层训练池的来源与骨架连接隔离内部划分。验证标签相同，只改变训练组成。比较指标是合并后的来源等权 MAE。三种策略先按同一组固定参数比较。

评价 C 的参考包括阶段 B RF B、RF B+M、RF ALL_DEV，以及本轮 G1 固定参数 RF-F04。G1 与 ALL_DEV 的训练图已核对为完全一致。配对区间沿用阶段 B 的研究内聚合和成分重抽样。M3 没有重抽阶段 B 的十个供体种子。

预处理删除完全无变异和近似常量列。Ridge/SVR 在训练侧标准化描述符，过小标准差的缩放因子设为 1。ECFP 保持 0/1。LightGBM 的 subsample_freq 为 1。特征处理只在对应训练分区拟合。

N-only Median 使用图总权重为 1 的加权中位数。

## 实际预算

G1 的 12 个筛选组合共 180 次内部拟合，Optuna 共 900 次，合计 1080 次。F01、F04、Median 和 Ridge 基线共 105 次，另计。G2 和 G3 的 Optuna 为 0 次试验，少于 G1 的 30 次；原因是 G1 的搜索没有降低外层来源等权 MAE，资源优先保证 G1。G2/G3 仍完成了固定参数的内部拟合和外层重拟合。

Top50/Top100 没有执行。若执行，筛选对象是 RDKit 描述符列，不是指纹位，也不是整个组合空间。

没有增加 Mordred、PaDEL、GPU 神经网络、CREST、分子动力学、多任务学习或额外参数搜索。
