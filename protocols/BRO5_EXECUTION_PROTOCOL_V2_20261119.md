## 1. 研究问题、假设以及主要与扩展估计量

研究对象：高分子量非大环分子，不将其等同于PROTAC或非肽类。沿用RDKit最大计算环≥12的大环操作定义。

主要终点 Caco-2 A→B Papp，y=log10(Papp [cm/s])；不是纯被动渗透性。PAMPA按可比较系数定义独立重复，不混合终点训练。主评价为500<MW≤700 Da非大环；严格留出为MW>700 Da非大环，开发分子≤700 Da。

H1（训练数据组成）：等数量、同分子量分箱的M/N供体可能存在不同的预测迁移贡献。
H2（分子表征）：在相同算法、训练/测试对象下，构象表征可能改变预测误差。
H3（交互）：加入3D特征可能改变M与N增广策略的相对收益。
H4（物理化学解释）：环境依赖的极性暴露、构象紧凑度和分子内氢键可能与实验渗透性及2D模型误差相关。所检验为统计关联和机制一致性，不是膜穿越的直接因果证明。

主要统计仍保留V1.0的 Caco-2、RF+2D、SOURCE_CONNECTIVITY、优先+50、来源等权的 Delta_NM=MAE(B+N)-MAE(B+M)，双侧95% CI。B、S、M、N定义及预算同V1.0。新增关键的次要估计量：
- Delta_3D(arm,algorithm)=MAE(2D+3D)-MAE(2D)，负值表示误差减小。
- I_3D(algorithm)=Delta_NM(2D+3D)-Delta_NM(2D)，使用完全配对的训练成员、测试标签、抽样种子。若原Delta_NM<0，正的I_3D可能表示非大环优势减弱，也可能发生反转，须同时报告两项Delta及其符号，不能仅以I符号宣称差距缩小。
- Delta_GNN=MAE(D-MPNN)-MAE(RF)，同数据成员及相同表征层级；不把算法与特征表示的差异解释为单一因果效应。
- ALL_DEV全量模型的预测性能单列，不能代替等预算估计量。

H1为原始主要分析，H2/H3为关键扩展分析；预设RF的I_3D作为主要3D扩展对比，D-MPNN的I_3D为跨算法重复。其他对照与MD均为次要/探索性。若进行推断性多重检验，扩展对比按预先冻结的检验家族Holm校正。不得按结果挑选最有利的表征、模型或溶剂。

## 4. B：全局封存、严格来源隔离及2D核心实验

执行V1.0第3、4节。每个终点先封存全部合格>700 Da非大环，开发池剔除对应研究来源、连接ID和FP06相似性组，限制MW≤700。主SOURCE_CONNECTIVITY同时隔离来源与连接关系；SOURCE_FP06沿用Morgan Tanimoto≥0.6连通组，在相同测试成员上加严训练侧隔离。FP06并非实验确认的药化系列。来源分组首选5折，4、3折为预设容量降级；重复分子跨折保守暂缓。外层测试只评价500–700 Da非大环。内层只在外层训练中进行选择。全局封存不因后续3D资格失败而重开。涉及跨终点预训练/迁移时必须采用两终点封存来源/连接/相似组的并集排除，否则不作严格比较。

B/S/M/N固定定义：B为≤500 Da非大环基础；S为额外不重复的≤500 Da非大环；M/N为500<MW≤700的大环/非大环。供体按不同图、连接组不重复，M/N按四个50 Da区间配平。依据V1.0只按容量在(500,50),(500,25),(250,50),(250,25)中选择，先5折再4/3折；+50优先，+25次要。B+S、B+M、B+N共用同一次B、测试对象。预算统计包括删除最大M来源、严格FP06及PAMPA。十个种子17,29,42,71,101,137,271,314,577,911；+25嵌套于+50。若容量不足，如实报告，不借用封存数据。

2D模型：训练中位数、ECFP4 Tanimoto kNN(k=5)、Ridge(13个二维描述符、alpha=1)、RF(二维描述符+ECFP4、500trees、max_features=0.5、min_samples_leaf=2)沿用V1.0。特征、填补和缩放仅在各训练折拟合。图等权训练，多研究/条件标签不重复放大权重。get all development ALL_DEV独立于等预算试验。保留固定统计方式和OOF。完成二维基线即可推动后续模块，不需要等待MD。

## 5. C：深度学习与跨空间学习

### 5.1 模型体系和公平控制

| 模型 | 输入 | 优先级 |
| --- | --- | --- |
| Median / kNN / Ridge | 标签、ECFP4、二维理化 | 基线 |
| RF | 13二维描述符+ECFP4 | 原主要模型 |
| XGBoost | 与RF同2D特征 | 核心传统非线性对照 |
| Chemprop D-MPNN | 2D分子图+固定二维理化辅助向量 | 核心深度模型 |
| RF+3D | RF的2D特征+构象集描述符 | 核心3D对照 |
| D-MPNN+3D | 相同D-MPNN图和二维向量+同一3D描述符 | 核心3D对照 |
| 预训练编码器、3D-GNN、多任务模型 | 跨数据/空间表征 | 条件性扩展 |

纯图D-MPNN另作消融，避免把额外2D特征或特征数变化误写成3D贡献。D-MPNN不要求击败传统模型；预算小样本及ALL_DEV同时评价，不将更大训练集的效果归于算法本身。

### 5.2 参数和训练规则（建议起点，先在开发侧锁定）

- XGBoost回归：square error，树数500，max_depth=4，learning_rate=0.05，subsample=0.8，colsample_bytree=0.8，reg_lambda=1；小规模内层网格可预登记。超参数、CPU/GPU版本均保存。
- Chemprop：锁定实际兼容版本；D-MPNN depth=3、hidden size=300、FFN hidden=300、2层、dropout=0.1、batch=32、最多100 epochs为试算候选。选择有限网格（depth 3/5，hidden 128/300，dropout 0.0/0.1），不得未经登记扩大搜索。仅训练折内部按来源及化学组划分，early stopping patience=15；最终外层拟合按内层选定epoch数重训，不能以外层测试损失早停。对小预算固定简洁配置优先，按算法为各臂采用同一预设选参规则及搜索预算。
- 使用固定相同采样成员、分子图、标签权重和测试成员；记录消息传递、任务回归loss、target/feature scaling及随机初始化。缩放参数仅训练拟合且测试逆转换；结构生成可缓存但不能用测试标签。
- 随机初始化/训练种子与供体种子分别记录。10次供体抽样不视为独立测试样本；如多初始化做集成，先固定重复数与汇总方式。
- 预训练模型若加入，审计模型、权重来源、训练语料与监督标签重叠；不明则只作参考，不作为严格主结论。多任务/迁移学习仅在明确不同终点含义并通过全局隔离后探索。

输出 model_configs、inner_cv_scores、training_curves、OOF、失败日志、模型checkpoint及版本/hash；不得上传未核实许可的模型材料。D-MPNN失败或数据不足须记录，不能只呈现成功折。

## 6. D：构象集及3D表征因子实验

### 6.1 分级构象工作流

L1 为全体合格分子的快速构象集，必须实施可行性试验并尽可能完成；L2 为代表性分子的高质量溶剂构象采样；L3为E阶段动力学。所有规模为预设计划/上限目标，不是实测可行性结论。

L1 RDKit ETKDGv3 + MMFF94s：
1. 固定程序/版本、状态、显式氢、手性约束、macrocycle torsion选项、随机种子。试算开发侧按拓扑、MW、RotB、电荷分层的约60–100个图，不按预测误差选择；候选构象数50、100、200，记录失败和运行时间。
2. 每个构象MMFF94s优化（先检查参数，建议最多1000 iterations）；未收敛分开记录。无MMFF参数不静默用UFF替代；UFF另作标记敏感性或判3D失败。检查连接关系、立体、严重碰撞。
3. 优化后重原子RMSD去重，建议0.75 Å（宏环和柔性子集测试0.5/1.0 Å）；以同一状态、同力场相对能量筛选，默认保留≤10 kcal/mol且最多50个去重代表构象，另做5/15 kcal/mol敏感性。能量阈值/数量为待试算参数，不能按测试精度选。
4. pilot按50→100→200构象检查polar SASA及Rgyr中位数、低分位数等稳定性、独立生成seed重复性和CPU成本。预登记例如中位数相对变化≤5%（接近0使用绝对阈值，polar SASA 2 Å²、Rgyr 0.1 Å）在至少80%试算图满足的参考门槛；报告未满足类别，按结构复杂度预定加大采样或明确限制。ETKDG频率和MMFF能量不等于真实平衡构象分布。
5. 以未加权构象统计为主；输出最小、10%分位、中位数、90%分位、最大、IQR（可选SD），同一描述符固定定义。能量加权仅作带假设敏感性，不跨环境比较原始势能。

### 6.2 描述符规范

| 描述符 | 定义/用途 |
| --- | --- |
| Rgyr | 质量加权回转半径，Å |
| Total SASA / Polar SASA | 固定原子半径、1.4 Å探针、固定SASA算法；polar定义为N/O及其相连氢的面积，其他极性元素另做统一规则，保存原子掩码 |
| Relative polar SASA | Polar SASA / Total SASA |
| IMHB | 基于明确供体/受体、D···A≤3.5 Å且D–H···A≥150°，排除共价局部邻近，规则固定 |
| IMHB fraction | 构象集中几何满足的比例；不是L1热力学占有率 |
| Asphericity / NPR1 / NPR2 | 构象形状 |
| Molecular volume | 固定算法和网格 |
| End-to-end distance | 仅在可一致定义连接子端点的双功能分子子集中分析，不作为全库必需特征 |

明确区别TPSA、polar SASA与文献不同3D PSA算法；不直接互换阈值。主3D特征向量在pilot后根据定义、计算稳定性和缺失率锁定，不根据外层/封存性能筛选；降维/缩放仅训练拟合。3D不包含模拟失败与来源作为捷径预测特征，失败率单独报告。

### 6.4 L2：CREST/GFN-xTB高质量构象采样

目标100–300个开发集代表分子，先试算12–20个、按拓扑、MW、柔性、状态及来源分层；在计算前登记选择规则。CREST+GFN2-xTB（或经小规模测试选定兼容方法），水/低极性环境如氯仿采用同一实现支持的隐式溶剂（例如ALPB，实际版本和溶剂参数必须核验），保持化学状态和电荷一致。建议搜索能量窗6 kcal/mol为起始候选；记录独立种子、模型、搜索参数、成功率、重复采样重叠、资源开销和构象合并规则。若低极性状态的质子化与水相不同，独立标记并做敏感性，不能直接把不同电荷状态的差归于折叠。
计算固定描述符及DeltaPolarSASA=PSASA_water-PSASA_lowpolar、DeltaRgyr=Rgyr_water-Rgyr_lowpolar；比较分布和代表构象而非仅最低能结构。分溶剂内部去重、能量统计，不跨溶剂原始势能比较。CREST/xTB未必对所有高MW、带电或特殊元素分子可靠，需记录参数适用和失败类别。
L2定位：检验L1快速构象描述符的稳健性、为E提供独立起始构象、形成环境响应机制子研究；如仅部分样本有L2特征，不将其直接混入全库3D模型当作统一输入；配对比较需同子集及独立容量审核。数量依实测资源与收敛性确定。

## 7. E：MD/WT-MetaD机制研究

### 7.1 选择策略及规模

以开发集已确认立体化学/化学状态的分子为来源，优先在单一可解释终点中选取；主机制模块优先Caco-2，PAMPA作为更偏被动过程的独立辅助，不能把Caco-2关联解释为排除转运。预先按同终点的开发标签分位形成高/低组（建议上下四分位），按大环/非大环形成4组，每组5–10个、目标20–40个。尽可能在同来源/协议内匹配MW、TPSA、cLogP，并限制同一FP06组贡献；缺少可匹配样本时显示匹配失衡、缩减范围或报告不可行。优先选择开发侧分子，不使用封存标签或误差事后挑选；若做基线残差关联，采用固定2D折外预测而非训练内残差。登记全部候选、选择/排除原因和随机种子。

### 7.2 模拟技术规范与试算

- 先选择4–8个代表分子做端到端pilot（覆盖拓扑、柔性、电荷），从不同独立低能构象启动。GROMACS或OpenMM；GAFF2+AM1-BCC或合适OpenFF参数，统一参数方案；可电离分子记录微观状态和电荷，检查参数质量、扭转项、净电荷、溶剂兼容性。不能在未知/缺失参数时默默模拟。
- 水相采用与力场匹配的显式水（如TIP3P）；低极性相使用经参数和密度验证的显式氯仿等溶剂。固定力场/电荷、溶剂盒与边界，最小溶质边缘距离建议≥1.2 nm并检查高柔性分子周期自接触；带电体系记录中和、电解质策略及低极性溶剂电荷伪影。低极性相只是疏水环境代理，不是真实膜。
- 最小化→NVT→NPT→生产期；起始建议298–300 K、1 bar、约束含氢键时2 fs、PME（显式体系）及与力场匹配的截断设置；记录压力/温度控制器、平衡长度、坐标输出间隔和随机种子。实际参数以平台和pilot验证后冻结配置为准，非现成生产设置。
- 生产期初步100 ns × 3独立重复 × 2环境；20–40个分子对应12–24 µs聚合生产轨迹，另计平衡和增强采样。先测每体系ns/day、资源占用、硬盘需求、力场与采样质量；最终规模由资源与科学质量共同确定，不把100 ns视为必然收敛。
- 收敛核查：能量、温度、密度及约束异常；构象聚类、独立轨迹间分布、block平均、autocorrelation/有效样本量、前后半轨迹分布重叠及折叠态转换次数。阈值在pilot后、正式分析前登记（例如PSASA/Rgyr均值的分块与重复差异可容忍范围，至少观察关键态往返或说明未观察）。不达标可按预定规则延长/更换增强采样；否则报告非收敛，不画作定量平衡自由能。不能将逐帧样本当作独立分子。
- WT-MetaD是柔性分子采样不足时的重点扩展；优先评估Rgyr、polar SASA或有物理定义的氢键/折叠坐标能否描述慢变量，使用实际兼容的PLUMED/引擎。偏置因子、高斯宽度/高度、沉积步长由pilot波动和方法依据预定；不在未试算时虚构最终参数。检查独立重复、自由能面时间稳定性、正反转换及重加权有效样本，不能从偏置轨迹直接计算平衡占有率。常规MD未充分采样时只展示有限轨迹分布和代表构象。
- 不将显式膜PMF作为必做内容。若增加4–8个代表分子的umbrella sampling，应另立协议确定膜组成、插入坐标、取向/慢变量、窗口覆盖和收敛；PMF不是直接的Papp预测，需额外动力学/扩散假设才能估计渗透系数。

### 7.3 机制分析及交付

对每个分子的不同环境报告Rgyr、polar/total SASA、IMHB几何占有率、构象簇与不确定性；定义水相减低极性相的差值和方向；分层比较高低渗透性和拓扑类别。以分子为分析单位、独立轨迹及block用于不确定性；可做匹配配对、来源分层或开发OOF误差关联（Spearman等），不把帧数当作统计样本量。谨慎讨论去溶剂化、折叠/暴露极性，不声称MD证明跨膜过程或Caco-2传输机制。

输出 md_selection.csv、parameter_manifest.csv、md_configs、trajectory_manifest.csv、replica_qc.csv、convergence_report.csv、ensemble_statistics.csv、solvent_response.csv、case_study_figures、运行环境、脚本和hash；轨迹本身按许可/存储条件归档。机制模块最低交付为已登记pilot与质量报告；正式机制结果只有参数和收敛检查通过才进入主文。若资源或适用性不足，保留L1/L2主线，MD作为限制/后续，不伪造完整模拟。

## 8. F：严格外推、统计、可靠性及稳健性

全部开发侧模型配置、3D资格/特征、机制选择及训练预算已锁定后，登记 lock_manifest，才评价全局>700 Da留出。对2D全量及3D合格子集分别报告固定模型预测；3D留出子集的2D对照须同测试及训练样本，覆盖差异透明。封存标签不得反向调整任何模型、构象选择或数据清洗。历史已审核标签不宣称双盲、新采外部数据；未来新来源需重新排查重叠。

沿用V1.0统计：来源等权为主，分子等权并列；误差先在相同图–来源内条件等权，再在来源/图层面汇总；先汇总相同标签各重复种子的绝对误差。10,000次配对cluster bootstrap(seed=271828)，来源或共享连接关系的来源连通组件为单位，严格版检查FP06依赖；保留四臂及全部配对。报告组件数和最大占比；组件过少/高度集中则CI探索或不可估计。报告MAE、RMSE、Spearman、pooled OOF R²和signed error，不平均极小折R²。全部指标与交互项由独立脚本复算。重复种子不是独立样本；CI条件于锁定设计。

必要稳健性：SOURCE_FP06同测试集、去最大M训练来源、PAMPA独立重复、3D子集覆盖比较；若容量不足按规则降级或报告不可行。次要：标签聚合、无环肽排除、实验干预、相似组限额。适用域作为增强研究的必要评估：最近邻Tanimoto、模型训练侧覆盖、MW/极性/柔性及集成离散度与折外绝对误差；可靠性模型或阈值只用开发内嵌套OOF拟合，评价风险–覆盖曲线及误差校准，不能用最终留出选择阈值。无足够校准样本时报告描述性AD，不声称概率可靠性。新外部数据、预训练模型、多任务或显式膜计算条件性增加。
