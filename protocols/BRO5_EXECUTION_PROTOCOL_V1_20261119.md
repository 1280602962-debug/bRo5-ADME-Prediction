## 1. 科学问题与主要估计量

在相同常规非大环基础集 B、相同算法及相同测试对象上，增加相同数量的常规非大环 S、高分子量大环 M、高分子量非大环 N，比较预测增益。M/N 的分子量分箱计数完全匹配。研究实际可获得训练数据的贡献，而不是识别大环拓扑的因果效应。

主要终点：Caco-2 A→B Papp，y=log10(Papp [cm/s])，连续值回归；并非纯被动膜渗透性。主要目标空间：500<MW≤700 Da 非大环。主要比较：RF、来源+连接关系隔离、首选 +50 预算下，B+N 与 B+M 的来源等权 MAE 差（双侧）；负值支持 N 的较低误差。+25 为次要预算，若容量不足按第4节规则降级。PAMPA 独立重复，不与 Caco-2 合并训练。MW>700 Da 非大环为全局封存的严格分子量外推集，使用当前汇总中的留出数据，不称新采集外部验证。历史审核已查看部分标签/数量，因此不声称前瞻双盲。B+S 与 B、B+M 与 B、B+N 与 B、N 与 S 等为次要比较；全数据模型回答实际预测能力而非等预算数据贡献。

不预设 N 优于 M；不显著不等于等效。无需新增 wet lab、深度网络或 3D 为开工条件。

### 2.3 终点、结构、标签

Caco-2 主任务仅允许明确 A→B Papp；纳入常规/未知抑制剂状态的明确 A→B 表观渗透性，已知加抑制剂、诱导/转运体改造等非默认条件标签保留但与普通条件分开，主分析暂缓已知干预，作为条件敏感性；不得将 MDCK、B→A、ER、方向不明或其他实验混入。对来源/样品的条件签名记录 pH、浓度、温度、时间、抑制剂、细胞系（有则记录，缺失明确标记）。PAMPA 预先区分 Peff/Papp/P0/intrinsic/apparent 及协议；冻结前按语义选取可比较的主系数任务，不根据模型性能选；如系数未明，单列宽口径通用 PAMPA 敏感性，不宣称同质物理终点；如果可追溯容量不足，PAMPA降为探索性，不阻塞 Caco-2。

结构沿用历史标准化规则及大环筛选（RDKit最大计算环≥12）；固定盐/母体、芳香化、电荷及互变异构规范版本；不自动枚举手性、不以预测误差调结构。保留 canonical isomeric SMILES、Graph_ID、连接关系 ID（忽略手性）、MW、最大环、未指定手性标记、分子类别（PROTAC/肽/其他/未知，未能确认即未知）。分子量按同一标准化母体未四舍五入值分为 ≤500、500<MW≤700、>700；>700 不等于700–1000。原始记录不覆盖。

标签转换：Papp 以 cm/s 计，若以10^-6 cm/s报告则 log10(原数)-6；已经 log10(cm/s) 的字段不可再取对数。单位及限定符逐行留存。只在同一结构、原始研究、终点、方向及兼容条件/实验组内聚合，不跨来源平均，不将缺失条件自动视为相同；未知但可追溯的同一实验组可聚合，无依据则分留或暂缓。默认主标签采用组内 log10 值中位数（抗极端值，设计建议）；线性均值再取 log10、log均值作为预设敏感性，组内只有1个值三者相同。兼容性判定优先于聚合方式。逐条保留来源及转换公式。最终一项结构–研究–条件标签一行；同一研究的多个兼容/合法条件不重复充当独立分子。

## 3. 阶段二：全局封存、严格来源隔离

### 3.1 来源及结构分组

source_id = 原始研究 DOI 或经证据归并的研究ID，不等于数据库名或实验室。采用 DOI/PMID/研究别名归并；来源未知的记录不进入严格验证。以连接关系 ID 防同分子不同手性表示跨集合。严格敏感性使用历史 Morgan Tanimoto≥0.6 连通分组 FP06（固定历史指纹设置，记录 RDKit、半径、bit数、手性设置；若不能复现先冻结新定义并记录差异）；连通组不等同药化系列。全数据仅基于结构和来源计算分组，可使用其结构信息建立隔离，不能以测试标签/残差选择划分。

### 3.2 封存 >700 Da

每个终点将全部合格 >700 Da 非大环标签列为 holdout（按 graph/source/condition 去重规则），开发池限定 MW≤700；从开发池移除 holdout 关联的所有原始研究、连接关系和 FP06组。主分析与严格敏感性共享这套保守的全局开发池，避免根据 holdout 结果返工。列出移除原因和各原因重叠，统计保留/损耗；不得为达到预算把封存数据返还开发集。若无法达到共同预算，执行预设降级或报告不可行。封存文件与 hash、保留集成员可复核；测试标签不用于分组平衡、特征/参数选择、归一化拟合、模型选择等。历史标签已审核，称锁定留出而非双盲外部数据。

### 3.3 开发集外层与内层

来源分组外层首选5折，采用预先指定的贪心平衡（按来源的目标非大环图数从大到小分到当前最小折；并列以 SHA256('20261119'+study_id) 打破）；仅按结构计数/来源不看 y。纯训练来源亦按此固定规则分配，不能在 heldout source 内训练。源间共享连接关系采用来源折后全局暂缓跨折连接组（保守且可审计，所有比较共享评价成员）；严格 FP06 版本使用相同外层测试成员，训练侧额外剔除与测试 FP06 组重叠的记录，不强制按 FP06 重划测试折。对于重复图在同一折、多个研究或条件的标签，保留并依第5节加权。对来源和连接组共享关系特别巨大的情况报告损耗，禁止静默拆组。

每个外层折：测试仅该折 500<MW≤700 非大环；同折其他类别不训练；训练从其余折可用池抽取 B/S/M/N。严格版本额外剔除测试 FP06组。内层仅在外层训练池内做来源+连接关系隔离（如需调参），严格版本也隔离 FP06，任何测试标签均不可进入调参。首轮固定超参数，无需为调参耗费额外容量；若后续调参使用3折内层，选择规则预先锁定，不可用外层误差选择后仍称无偏主结果。后续模型选型仅在开发集完成，外推开封前登记。固定随机种子；五折容量不足允许按预设5→4→3折重算，只以计数、容量、隔离为依据，先记所有失败候选，不能按性能选折。每个测试折至少有两个研究及非空目标测试样本，报告每折规模和最大来源比例；不足则报告不可行/探索性。

### 3.4 划分与容量交付

splits/：holdout_members.csv、development_members.csv、outer_members.csv.gz、inner_members.csv.gz（若调参）、split_exclusions.csv.gz、fold_capacity.csv、split_config.json、split_verification.json、split_manifest.csv。逐折报告 B/S池、M/N四个50Da区间、来源/FP06组数、最大来源规模，含去最大大环来源版本、严格FP06版本。对每一折/每一模型/每种采样验证：

- 容量重算和隔离检查必须通过才可进入正式训练。

## 4. 阶段三：固定预算与基线训练

### 4.1 预算预设与自动降级

B为 MW≤500 非大环；S同一分子量类但与B连接ID不重复；M/N分别为500<MW≤700大环和非大环。预算按不同 Graph_ID（并避免同连接组重复抽取占预算；以连接组代表图数量复核）而不是标签条数。每个选中图的全部合格训练标签保留，图总权重相同；不同来源标签不跨来源聚合。

M/N 使用(500,550]、(550,600]、(600,650]、(650,700]四区间。每折 c_j=min(M_j,N_j)，配平容量 C=sum(c_j)。在选定 k 时按 c_j/C 比例分配 k_j，最大余数法且 k_j≤c_j，平局按分箱升序；M和N分别无放回抽 k_j。小分子池必须≥b+k且连接组不重复。对两种来源敏感性共同测试成员，原始和删除最大来源的容量分别记录；最大来源按该折可用M池 graph数决定，平局 hash。删除仅发生在训练侧M，主B/S/N不改变；如同一M图还有其他可用来源标签，从剩余来源重建候选。另可将该源从全部训练组移除作为更强敏感性，不混为主比较。

优先选择 Caco-2 来源隔离主评价的5折、b=500、k=50；不能满足先检验 k=25，再检验 b=250、k=50/25（250为容量不足的预设降级，不是新增科学结论），再按5→4→3折重算；若无可行组合停止等预算主实验，输出容量瓶颈。优先级固定：先尝试5折内(500,50),(500,25),(250,50),(250,25)，再4、3折同序。k=50可行时 k=25次要；若主预算降为25，则不强行新增更小预算，记录偏离。b=1000可在冻结前核查容量作为敏感性，不根据误差取舍。外推集全局冻结后完整开发池需满足同预算，不足则同样预先降级或把外推增广标为探索性；主比较不借用封存数据。严格FP06、删除最大M来源与PAMPA尽量沿用相同b/k；容量不足则在看性能前降预算为25或报告不可行；使用不同预算的结果不直接当作同预算重复。所有分支、容量、最终选择和理由写入 budget_decision.json 并锁定；不得在看结果后选预算。

B/S/M/N每折重复10次，种子固定 17,29,42,71,101,137,271,314,577,911；以 endpoint/fold/seed/arm 派生确定性种子，B和各arm共享，独立供体随机池按排序后无放回抽样；同一个种子内以嵌套采样保证+25是+50子集（按照+50分箱内容量及最大余数分配）。在比较两种来源变体时尽可能采用共同分箱配额，优先共享B/S/N成员；若无法实现要明确报告，不伪称配对完全控制。每次同一测试集、算法和训练特征规则。输出 sampling_members.csv.gz 和重复样本/来源/相似组统计。

### 4.2 首轮模型及特征

主模型RF，固定超参数以避免外层选择偏差；以下为协议提议、须在执行前写入锁定config：
- Median：训练标签按图权重的加权中位数。
- Tanimoto kNN：Morgan ECFP4（radius=2, 2048 bit, useChirality=False, useFeatures=False），k=5邻居（不足取全部）；每个训练图代表预测值为其合格标签中位数，仅在训练折内求取；按 Tanimoto 相似度加权，零相似度回退中位数，平局 Graph_ID 排序。
- Ridge：理化描述符，alpha=1.0，训练折内中位数填缺及 StandardScaler；拟合截距；样本按图等权。
- RF：理化描述符+ECFP4，n_estimators=500, max_features=0.5, min_samples_leaf=2, max_depth=None, bootstrap=True, random_state=派生种子, n_jobs按设备记录；非有限特征训练内中位数填缺，禁止使用研究ID/数据库名作为特征。图权重分配到标签，记录RF样本权重不保证bootstrap按图抽样（可用图级重抽作为敏感性）。
- 描述符固定 MW、HeavyAtomCount、MolLogP、TPSA、HBD、HBA、NumRotatableBonds、FractionCSP3、RingCount、NumAromaticRings、formal charge、最大计算环、TPSA/MW；记录 RDKit 版本、缺失率。对全部特征不可计算的结构按统一预规则暂缓并在冻结前重算容量。
- 首轮四模型在相同外层测试成员和样本预算上比较；RF主要，其他为稳健性/基线。另训练 ALL_DEV：每折所有合格训练数据（≤700的非大环/大环，不受b/k约束），与受控试验分开报告。若需XGBoost/D-MPNN或调参，依据开发集研究需要，新增配置/版本，外推标签开封前完成。不以首轮外层选择最佳模型再报告为无偏主结果。

## 5. 统计、输出与验收

### 5.1 主要统计

评价单位为结构–来源–条件标签，避免同一图的多个条件/来源过度计权。先取每条标签绝对误差，再在同一来源内每个 graph 的条件标签等权平均。来源等权 MAE = 对各 test study 的图等权 MAE 再等权平均；分子等权 MAE = 对各 test graph 的来源/条件平均误差再等权平均。重复抽样的绝对误差先按 graph/source/condition 对10个种子平均，再汇总；不把10次训练当独立样本。另行报告按种子波动和集成预测性能（如有，不混为主要指标）。主要差值 Δ=MAE_source(B+N)-MAE_source(B+M)。同图同来源同条件的两臂预测严格配对；报告分子等权差、对B及S的差、RMSE、Spearman、汇总OOF R²（R²分母为0时NA，不平均小折R²）、signed error。

95% CI 使用10,000次配对 cluster bootstrap，seed=271828。若各研究不共享图，按 study_id 整簇重抽；若共享图/连接组，构建 study–connectivity 二部图连通组件作为重抽单位，并报告有效组件数与最大组件规模；严格版另检查 FP06依赖，必要时以study-FP06组件重抽作为敏感性。同一重抽样本用于所有模型，保留配对和组内权重；来源等权差及分子等权差分别重算。若组件不足/高度单一（例如<10组为预设警示），CI仅探索性或无法估计，报告组级差异和leave-one-source/cluster-out敏感性。区间是条件于锁定数据、划分和训练种子的测试误差不确定性，不是全部训练抽样方差。主要一个对比，双侧95% CI；其他比较探索性，若给多重检验显著性则预先用Holm校正。区间跨0不代表等效，不宣称拓扑因果效应。

### 5.2 输出

runs/<run_id>/：config.json、environment.lock、code_commit.txt、input_hashes.json、sampling_members.csv.gz、oof_predictions.csv.gz（endpoint/fold/seed/arm/model/label_id/graph_id/study_id/condition_id/y/yhat）、metrics_by_fold.csv、metrics_pooled.csv、paired_deltas.csv（comparison/weighting/n_graphs/n_studies/n_clusters/estimate/CI）、seed_variability.csv、validation_report.json、run.log、manifest.csv。汇总前逐行校验所有臂的评价ID相同、种子与折完整、预测有限、无重复键、样本预算正确、隔离无交叉；失败折不静默跳过或补值。用独立脚本从预测重算指标与CI。

第一阶段完整交付（含首轮训练）不要求达到某个R²：V1.0行级追溯、数据与划分hash、预算复算证据、无泄漏、同批测试对象OOF、来源/分子等权MAE、主要N-M配对ΔMAE和CI（或有充分理由的不可估计）。任何缺项标记FAIL/PENDING，不能写成已完成。

## 6. 阶段四：严格外推与稳健性

开发集方法及数据组别、超参数、主要/次要指标锁定后才进行 >700 Da 标签评估。训练池为完整的≤700 Da开发池（仍排除全部封存集关联来源、连接组、FP06），以已冻结b/k及10个抽样种子重新训练B/S/M/N和ALL_DEV，报告全部封存测试预测、与开发集500–700结果分开汇总。评估同一测试标签，按上述配对统计；不基于外推误差修改模型或去掉困难分子。若外推容量无法满足预算，只进行可行的预登记比较，明确探索性。若后续找到未参与构建的新公开数据，只在新独立版本评估，核查同原研究及化学重叠。

必要稳健性：
1. Caco-2来源+FP06隔离（同测试成员），主要模型+可行同预算；
2. 移除最大M训练来源（尤其旧版PAMPA 1353/1483≈91.2%，新比例须复算），报告配平容量、来源/化学组分布，解释标签协议和组别混杂；
3. PAMPA独立重复核心对照，先冻结系数含义和预算；未能同预算时定性报告，不强行宣称复现；
4. 若结果依赖某来源、聚合方式或类别，则补充预设标签聚合、去无环肽、去已知干预及化学多样性抽样上限敏感性；不根据测试表现选最佳聚合。

条件性后续：XGBoost/D-MPNN、适用域/校准（仅开发集拟合）、新独立来源、明确手性结构的3D描述符。无实质增量不增加计算模块。
