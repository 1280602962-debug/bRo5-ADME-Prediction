# D2：构象感知供体选择（固定RF-2D）

科学问题：给定同一可用数据池和额外标签预算，构象相似性是否优于二维相似性选择？主分析仅Caco-2、D3D成功子集、原SOURCE_CONNECTIVITY外折、单一共同预算；RF-2D训练不含3D输入，V1/V2.1的H1、H2/H3独立保持。D3D资格/特征稳定性（含实际用于选择的所有3D统计量）须先冻结；不得更改原折或因选择失败重新开封。选择分数用结构，不用候选渗透性标签或目标域测试结构/标签。

## 1. 参考集与公平预算

每个外层fold/seed仅在该折允许的训练池中构建R：500<MW≤700 Da非大环且D3D合格的r个图，连接组不重复，按固定seed对graph_id排序后无放回抽取（不看y；外层测试及封存的source/connectivity/FP06规则仍适用）。R具有可用实验记录但标签全部掩码，仅作为结构参考。将R的全部连接组从B/M/N候选池排除，并验证与测试身份无交集；R不得作为任一策略监督训练数据或待选供体。若有内层选择，重新在内层训练池构建R/候选池及scaler；不得使用内层验证结构/标签作参考。目标设定是训练域内无标签参考，不是监督标签免费或外层转导学习。

共同预算优先按D3D主b/k，r=25→10；对每个原折及10seed先仅以数量检查，确认R分配后B池≥b、M/N四箱共同容量≥k。原折不变，次尝试既有(500,50),(500,25),(250,50),(250,25)去重后顺序、每组合r25再10；全折全seed采用同一可行b/k/r。如果无可行组合，DS01 NOT_ESTIMABLE；不借测试、不降低H1/H3。R随机分配方案、种子、成员及容量失败均保存；不能因性能重抽。以同一B、同一R、同一合格候选池和同一MW配额比较全部四种选择策略。供体选择在M/N池分别进行；B及R共享。仅选M或N时监督标签预算为b+k个不同graph（同图多兼容标签计数及权重另报），参考结构r、候选结构浏览总数及3D计算量单列；R原始标签已采集不代表实际未来采购成本为零。既有数据库回顾性排序，不宣称已完成前瞻实验采购或主动学习。

按V1四个MW区间计算共同capacity c_j=min(M_j,N_j)；最大余数分配k_j（平局按箱升序），冻结每fold/seed的配额，四策略及M/N同一k_j。预先按连接组选择固定代表图（若多图同组按graph_id最小，记录），每策略无放回选取；随机策略同样需满足3D资格、参考排除、配额及k。随机对照需重新生成，只有成员和候选池hash相同才可复用D01。

## 2. 四种供体选择与距离

| ID | 方法 | 规则 |
| --- | --- | --- |
| DS-RAND | MW-matched random | 箱内固定seed随机选k_j |
| DS-2D | 2D-guided | 按二维距离升序取k_j |
| DS-3D | 3D-guided | 按三维距离升序取k_j |
| DS-HYB | Hybrid-guided | 0.5二维＋0.5三维距离升序取k_j |

主距离参数固定，不按外层误差选alpha。D2D距离：ECFP4(沿用V1)的1-Tanimoto和连续13个二维理化描述符距离各权重0.5；D3D距离：锁定稳定构象描述符向量（只用预登记代表统计及定义，不加入实验标签、来源ID）。连续描述符在允许的B/R/M/N候选结构池上按中位数/IQR稳健缩放，零IQR或非有限尺度列按预登记规则移除，记录列和尺度；不使用任何评价结构拟合。距离为mean(min(abs(z_i-z_j)/5,1))，范围[0,1]。3D特征组按原始物理描述符（例如PSASA、Rgyr）先组内统计量平均，再各组等权，避免某个属性因统计量更多被重复放大。无合格3D组则停止DS。二维和三维各对同一R构成逐参考分子距离；Hybrid先对每对分子距离取0.5混合，再按目标参考最近5个距离（不足5取全部）的均值形成供体评分，DS-2D与DS-3D同样用最近5均值。混合不是分别取不同邻居后混合。箱内评分并列以graph_id排序；随机用稳定排序和固定派生seed。全部策略不按训练/测试误差或y排序。

## 3. 模型和估计量

仅RF-2D固定V1参数与图等权；同fold/seed的B、训练配置、测试label、候选池和参考一致，改变的只有被选中的供体。主效应DS01=0.5×[(MAE_HYB,M−MAE_2D,M)+(MAE_HYB,N−MAE_2D,N)]；来源等权，配对四臂bootstrap，分层两个差及CI分别列出。辅助HYB−RAND、3D−RAND、2D−RAND、HYB−2D按M/N报告；若两类方向相反必须解释，不能仅用平均断言跨拓扑普适。报告实际MW箱内分布、来源数/集中度、FP06多样性、选择重叠、最近邻覆盖、标签分布及参考成本，不宣称拓扑因果。只证明在指定候选/参考/表征/预算下的预测策略差异。

若正式DS01可运行且资源允许，预登记一个来源+FP06严格敏感性：RF-2D的HYB/2D两类供体，仍保持原测试并重建允许R/容量。若无共同支持报告不可估计。无需全部策略跨PAMPA、预算、模型重跑。D3构象加权属于条件性，须先锁定统一供体成员、尺度、alpha/sigma、权重截断、归一化、有效样本量 ESS=(sum w)^2/sum(w^2)，并比较同数量均匀权重与加权；不与D2首轮混跑。将选择与模型3D输入联合使用仅作新增2×2消融（同池随机/HYB×2D/2D+3D，不能直接归为选择收益），需要另登记资源和比较，不自动开启。
