## 正式准入证书及阶段顺序

A: 单位、身份、来源、行级修订 PASS；B: 全局封存与容量 PASS；P-B实现/度量/资源 PASS后允许正式H1（主预算、预测键、失败及配对统计已锁定）；D: 结构质量、完整D3D容量、同折B/M/N及稳定特征 PASS后允许H2/H3；DS须额外R和统一池/MW配额验证、五策略确定性及覆盖诊断实现通过；C: TL成对/权重/冻结/更新验证与资源PASS后允许C02；C03独立跨任务隔离/辅助标签预算PASS才运行；E分别按L2/MD物理质量、病例匹配和资源；F仅在相关模块完成或停止报告、所有拟评估方法预先锁定后一次性解封。没有未知成本的全规模任务获得授权。资源填报以compute_budget及实际expanded run matrix为准。

证书：phenomenon（真实预测尚未知）、experimental unit（未冻结）、measurement（仅计划）、intervention（待代码核对）、access/preprocessing（历史归档而非新版trace）、competitor delta（初步差异、未完成全文对标）、resource/yield（未实测）、joint dependency（已设计，待验收）。所有实测状态PENDING。若强制节点失败停止对应主张；负结果和宽CI不得自动变更研究问题。交付 gate_status.csv、capacity_report.csv、pilot_run_manifest.csv、pilot_resource_measurements.csv、actual_budget_lock.json、claim_survival_and_stop.md。先A/B，不要求先完成MD。
