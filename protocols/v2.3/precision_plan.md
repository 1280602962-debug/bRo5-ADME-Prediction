# V2.3 估计精度及独立信息量分析

目的不是用现有数据事后证明统计功效，也不是新增显著性门槛。保留P01及原H3/DS/TL估计量、方向、权重、10,000次配对cluster bootstrap、seed271828及既有Holm家族。报告独立研究来源、来源–连接组件（严格版另检查FP06）、组件大小/最大占比、图数、实际标签数、10个种子及有效的比较数；10次种子不增加独立n，帧不作独立分子。

## 1. 正式运行前训练侧估计

A/B完成数据和划分冻结后，不以外层/封存标签估算或决定成功阈值。先确定实际研究数、组件数及目标域分布。pilot仅使用指定外层训练池中再次按来源/连接隔离的内部目标域验证对象（最多2个原折，每折固定seed17，预算按内层容量，仅运行RF四臂；不得跨外层借标签）。若内层样本不足，报告精度未知，不改变主折。该pilot不代替正式OOF，也不根据效应方向选择新主假设。

对内部配对预测：每个label先绝对误差再配对差，按原图/来源权重汇总；仅有一个重复seed则明确只是先导变异。按原组件重抽法得到95%区间与宽度，报告组件少/巨型组件不确定性。可作设计敏感性：以中心化的内部配对组件误差为残差库，假设真实效应0、±0.1、±0.2 log单位，保持实际组件规模与来源权重进行10,000次重抽，对每一假设给出误差尺度/经验区间覆盖零比例（固定残差经验分布的条件情景，不是无条件power，不外推不同样本结构）。若选择将其用于功效分析，需另行预登记模拟真实独立组件分布和检验过程；此处只报告先导精度与可分辨尺度。0.1/0.2为讨论候选尺度，不是通用合格阈值或等效界值；结合可追溯同协议实验重复变异（若没有就报告未知）。
对具有不足10组件或明显单一组件主导的情形，沿V1/V2.1警示规则只报告描述/探索性区间、组件级结果，不做确认性宣称；不能靠更多bootstrap/seed补足。pilot预先固定执行及停止，不因结果不利追加样本或改变P01。正式预测模块的选择保持原预登记规则。

## 2. 正式OOF及留出

同样本配对、种子误差先平均、来源等权主、分子等权补充。每个正式关键比较P01/S01/S02/DS01/TL01及其适用留出，提供CI宽度及上下界、组件数和实际贡献权重、leave-one-source/component-out（在已经生成的固定预测上重新汇总，不反复挑模型；组件留一特别注明直接测试依赖），种子方差单列，不称全部训练抽样不确定性。报告95%CI与参考0.1/0.2的相对宽度；跨零不意味着等效/不存在效应。正式OOF/留出结果仅用于报告解释，不用于修改效果阈值、容量、模型、比较家族或外推集。没有完整配对则按原NOT_ESTIMABLE规则。
