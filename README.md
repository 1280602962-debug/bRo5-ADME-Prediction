# bRo5 permeability prediction

本仓库用于高分子量非大环化合物的渗透性预测及训练数据组成研究。

数据整理日期为 2026-11-18。当前数据属于可复核工作集，模型尚未训练，终点、标签聚合和正式划分仍需冻结。

## 数据归档

正在整理完整项目快照。仓库保存数据索引、校验清单、审核报告与复现脚本。大型原始数据库、文献附件及全量提取数据随项目快照保存于 Releases 分卷附件。

当前主要终点为 PAMPA 和 Caco-2 A→B。研究比较共同基础训练集分别增加等量常规分子量非大环、高分子量大环和高分子量非大环数据后的预测增益。

上游数据库和文献文件的权利及使用条件继续适用。
